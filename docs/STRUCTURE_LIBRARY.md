# Structure library
Approved feature: select two opposite corners of a 3D cuboid using a dedicated tool (left click A, right click B). Normalize min/max coordinates, inclusive bounds, visible selection outline, editable corners and volume preview. Server validates administrator, active construction session, dimension, project bounds and configurable volume cap.
Save named structures to a server-wide categorized library shared across projects. Preserve block states and optionally block entity data; inventory contents and entities disabled by default to prevent duplication, explicit administrator opt-in with sanitization. Use versioned Minecraft structure NBT and metadata, atomic writes, unique IDs, dependency checks and backups. Placement preview, adjustable anchor, rotation 90/180/270, mirror, explicit confirmation, air inclusion option, bounded batch placement and undo journal. No source blocks removed during capture. Test modded blocks, missing dependencies, restart persistence and undo. Implementation pending.
