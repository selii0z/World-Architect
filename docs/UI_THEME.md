# UI theme
Approved military olive style matching the Escape From Minecraft editor concept.
- Background: #1C201B
- Panels: #2C3427
- Primary buttons: #4C6039
- Accent and icons: #B6C69C
- Text: #E9EADF
Rounded panels and buttons, smooth readable typography, scrollable lists, visible hover and selection states. French-first labels. Use this palette throughout all project profiles. This is a design specification, not an implemented screen.
